# UPS Training – Day 3

Day 3 focused on conditional statements, loops, switch statements, user input, and basic Java problem-solving programs.

## Topics Covered
- `if`, `if-else`, nested `if`
- `switch`, `case`, `break`, and `default`
- `while`, `do-while`, and `for` loops
- `Scanner` for console input
- String comparison using `.equals()`
- Modulus operator (`%`)
- Basic calculations and validation

## Tasks
1. Valid Login
2. Movie Booking System
3. Print 10 to 1 using `while`
4. Print even numbers from 1 to 50 using `do-while`
5. Print even numbers between two numbers
6. Multiplication table using `for`
7. Odd or even using `switch`
8. Sum of first N natural numbers
9. Factorial of a number
10. Count digits in an integer
