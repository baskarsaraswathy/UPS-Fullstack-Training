# UPS Training – Day 3

Day 3 focused on conditional statements, loops, switch statements, user input, and practical Java programs.

## Topics Covered
- `if`, `if-else`, nested `if`, and `else-if`
- `switch`, `case`, `break`, and `default`
- `while`, `do-while`, and `for` loops
- `Scanner` for console input
- String comparison using `.equals()`
- Modulus operator (`%`)
- Arithmetic operations and validation

## Tasks and Programs

| Task | Program | Concept |
|---|---|---|
| 1. Valid Login | `Task1_ValidLogin.java` | Nested `if-else`, String comparison |
| 2. Movie Booking System | `Task2_MovieBooking.java` | `while`, `switch`, `if-else`, ticket pricing |
| 3. Print 10 to 1 | `Task3_WhileLoop.java` | `while` loop |
| 4. Even numbers from 1 to 50 | `Task4_DoWhileEven.java` | `do-while` loop |
| 5. Even numbers in a range | `Task5_EvenNumbersRange.java` | `if`, `%`, `while` |

| 7. Odd or even using switch | `Task7_OddEvenSwitch.java` | `switch` and `%` |
| 8. Sum of first N natural numbers | `Task8_SumNaturalNumbers.java` | `for` loop |
| 9. Factorial | `Task9_Factorial.java` | `for` loop |
| 10. Count digits | `Task10_CountDigits.java` | `while` loop and integer division |
