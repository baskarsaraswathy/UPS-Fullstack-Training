# Day 15 – HTML Practice Repository

## UPS Fullstack Training
This repository contains the simple multi-page website and separate practice programs for the HTML topics learned today.

## Project Structure
```text
Day15_HTML_Navigation/
├── home.html
├── login.html
├── register.html
├── contact.html
├── examples/
│   ├── anchor-targets.html
│   ├── marquee.html
│   ├── entities.html
│   ├── multimedia.html
│   └── tables-lists-dropdown.html
├── README.md
└── .gitignore
```

## Topics and Codes Included
- Anchor tag navigation and target values: `_blank`, `_self`, `_parent`, `_top`, and named frames
- Marquee tag and attributes: `behavior`, `direction`, `height`, `width`, `scrollamount`, `scrolldelay`, and `loop`
- HTML entities: `&nbsp;`, `&lt;`, `&gt;`, `&amp;`, `&quot;`, `&apos;`, `&copy;`, `&reg;`, and currency symbols
- Video and audio tags, `source`, controls, muted, loop, and YouTube iframe
- Form input types: text, password, number, email, tel, datetime-local, checkbox, date, file, radio, range, URL, submit, and reset
- `placeholder`, `required`, `textarea`, `label`, `select`, and `option`
- Tables using `table`, `tr`, `th`, `td`, `border`, `cellpadding`, `width`, and `colspan`
- Ordered lists (`ol`), unordered lists (`ul`), and list items (`li`)
- Relative paths and navigation between multiple HTML pages

## How to Run
1. Download and extract this repository.
2. Open the folder in VS Code or Antigravity.
3. Open `home.html` in a browser.
4. Use the links to open each practice example.

## Important Notes
- The `<marquee>` tag is obsolete; it is included only because it was part of the practice topics.
- For the multimedia example, add your own `sample-video.mp4` and `sample-audio.mp3` files inside the `examples` folder. Replace `VIDEO_ID` in the YouTube iframe with a real video ID.
- Forms are HTML practice examples only. They do not save data or provide real login/registration because no backend is connected.
