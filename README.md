## 🧭 About This Repository

Welcome to my **UPS Fullstack Training** repository!

This repository documents my day-by-day learning journey, practical exercises, assignments, and mini projects. Each folder represents the concepts covered on that day, along with the code I practised.

> 💡 **My approach:** Learn the concept → Understand the logic → Write the code → Test it → Save the progress.
