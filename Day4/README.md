# Day 4 – Java Learning

## Topics Covered
- Methods: declaration, calling, parameters, return values, code reusability
- Arrays: 1D arrays, 2D arrays, matrix operations
- Stack: LIFO (`push`, `pop`, `peek`)
- Queue: FIFO (`offer`, `poll`, `peek`)

## Programs
- Simple method example
- Calculator using methods
- Array example
- Matrix sum using methods
- Stack operations
- Queue operations

## Practice Tasks
1. Find the square of a number.
2. Check whether a number is even or odd.
3. Find the factorial of a number.
4. Find the sum of digits.
5. Check whether a number is prime.

## Learning Outcome
Practice Java methods, arrays, matrix operations, Stack, and Queue collections.
