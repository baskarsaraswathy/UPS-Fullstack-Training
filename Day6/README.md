# 🚀 Day 6 – Java OOP, Interfaces & Memory

> Learn daily. Code consistently. Build intelligently.

## 📚 What I Learned

### 1. Abstraction
- Hiding implementation details and showing essential features
- Abstract classes and abstract methods
- Implementing abstract methods in child classes

### 2. Interfaces
- Interface syntax
- Using `implements`
- Implementing interface methods as `public`
- Interface references pointing to implementing-class objects
- Why interfaces cannot be instantiated directly

### 3. Method Overriding & Runtime Polymorphism
- Overriding a parent-class method in child classes
- Using a parent reference with different child objects

### 4. Java Memory Basics
- Objects and instance fields are generally stored on the heap
- Local variables and method-call frames are associated with the stack
- Class metadata and method information are managed by the JVM

### 5. String Practice
- Common String built-in methods
- Removing spaces using `charAt()` and `length()`
- Reversing the order of words

### 6. Character Arrays
- Merging two character arrays using a single loop

### 7. Anagram
- Comparing two strings manually by matching each character once
