# Day 18 – CSS Media Queries, Filters and Animation

## Topics learned
- CSS Media Queries
- Responsive design for mobile and tablet
- CSS Filters: grayscale, blur, brightness, contrast, saturate, sepia and invert
- `drop-shadow()`
- CSS Animation and `@keyframes`
- Animation percentages, duration and iteration count
- `position: relative` and `position: absolute`
- Basic personal portfolio using HTML and CSS

## Folder structure
- `01-Media-Queries/` – screen-size based styling
- `02-CSS-Filters/` – image filter examples
- `03-CSS-Animation/` – moving and color-changing circle
- `04-Portfolio/` – basic portfolio using the topics learned
