# Day 14 - Peacock HTML Page

A beginner-friendly HTML webpage about the peacock, created during UPS Fullstack Training.

## Topics Practiced
- HTML headings and paragraphs
- Images and links
- Ordered and unordered lists
- Tables
- Horizontal rule
- Basic HTML page structure

## How to Run
1. Open `peacock.html` in a web browser.
2. To display the image, save a peacock photo as `peacock.jpg` in the same folder.

## Files
- `peacock.html` - webpage source code
- `peacock.jpg` - add your own peacock image here
