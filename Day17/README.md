# UPS Fullstack Training – Day 17
## CSS Layout and Advanced Styling

This repository contains the Day 17 CSS practice files prepared from the topics covered in training.

### Topics covered
- CSS selectors and selector combinations
- Combinators
- Pseudo-classes and pseudo-elements
- CSS box model
- `display`, `position`, and layout properties
- Flexbox
- CSS Grid
- Responsive design and media queries
- Transitions and basic animations

### Run the main practice page
1. Open the `Day17` folder in Antigravity IDE or VS Code.
2. Open `index.html`.
3. Make sure it links to `index.css`.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser.

### Important
The main page is a CSS Grid layout practice page. The smaller folders contain individual examples for each topic.
