# 🚀 Day 5 – Java OOP & String Practice

> Learn daily. Code consistently. Build intelligently.

## Topics Covered
- Polymorphism: Method Overloading, Constructor Overloading, Method Overriding
- String built-in methods
- String manipulation: reverse word order and remove spaces
- Anagram checking using manual character matching
- Merging two character arrays
- Abstraction: abstract classes and interfaces
- JVM memory basics: stack, heap, and method area

## Practice Programs

| Program | Description |
|---|---|
| `MethodOverloading.java` | Same method name with different parameters |
| `ConstructorOverloading.java` | Multiple constructors in one class |
| `MethodOverriding.java` | Child class overrides a parent method |
| `StringMethods.java` | Examples of common String methods |
| `ReverseWords.java` | Reverse the order of words |
| `RemoveSpaces.java` | Print a string without spaces using `charAt()` and `length()` |
| `Anagram.java` | Check anagrams using manual character matching |
| `MergeCharArrays.java` | Merge two character arrays using one loop |
| `AbstractClassExample.java` | Demonstrate abstraction with an abstract class |
| `InterfaceExample.java` | Demonstrate abstraction with an interface |

## Run a Program

Open CMD in the folder containing the Java file, then run:

```bash
javac FileName.java
java ClassName
```

Replace `FileName.java` and `ClassName` with the program's actual file and class names.

## Learning Outcome
Practised Java OOP concepts, String operations, array manipulation, abstraction, and basic JVM memory concepts.
