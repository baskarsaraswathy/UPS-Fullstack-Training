# 📅 Day 5 – Java OOP Concepts

## Topics Covered
- Encapsulation
- Inheritance
- Hierarchical Inheritance
- Method Overriding
- Runtime Polymorphism
- `static` keyword
- `final` keyword

## Programs

1. `ATM.java` – Encapsulation with deposit, check balance, and withdraw methods using a `while` loop.
2. `Animal.java` – Hierarchical inheritance and runtime polymorphism using `Animal`, `Dog`, and `Cat`.
3. `StaticExample.java` – Demonstrates a static variable and static method.
4. `FinalExample.java` – Demonstrates a final variable, method, and class.

## How to Run

Open CMD in this folder and compile/run each program:

```bash
javac ATM.java
java ATM
```

```bash
javac Animal.java
java Main
```

```bash
javac StaticExample.java
java StaticExample
```

```bash
javac FinalExample.java
java FinalExample
```

> Note: `Animal.java` contains a non-public `Main` class, so run it with `java Main`.
