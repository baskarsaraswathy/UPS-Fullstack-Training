# Day 10 – Classes, Objects & Constructors

## Concepts Learned
- Classes and Objects
- Constructors
- Parameterized Constructors
- `this` keyword
- Creating Objects
- Calling Methods

## Programs
1. `Main.java` – Student details using objects and constructors.
2. `Student.java` – Student class with a parameterized constructor.
3. `A.java` – Constructor example.
4. `today.java` – Object creation example.

## Key Takeaways
- A **class** is a blueprint for creating objects.
- An **object** is an instance of a class.
- A **constructor** initializes an object.
- The `this` keyword refers to the current object.

## Run the programs

```bash
javac Main.java Student.java
java Main
```

For the second example:

```bash
javac A.java today.java
java today
```

## Practice Task
Create an `Employee` class with employee ID, name, and salary. Initialize the values using a constructor and display the details.
