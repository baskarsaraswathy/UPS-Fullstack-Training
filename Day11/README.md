# Day 11 | MySQL Learning Log

A small practice repository from my UPS Java Full Stack Training.

## Today's focus
- Understanding relational databases
- Learning the purpose of SQL
- Creating and exploring a database
- Practising table definitions and record operations

## Folder guide
- `docs/concepts.md` — quick notes in my own learning format
- `sql/campus_store.sql` — a mini campus-store database exercise
- `practice-questions.md` — tasks to try without looking at the solution first

## How to run
1. Open MySQL Workbench or a MySQL-compatible SQL client.
2. Open `sql/campus_store.sql`.
3. Run the script from top to bottom.
4. Review each result set and inspect the tables.

## Reflection
The main takeaway today was learning how a database stores related information in tables and how SQL can create structures, add records, and retrieve useful results.

> Tip: Run practice scripts only on a learning database. Check the `WHERE` condition before running `UPDATE` or `DELETE`.
