# Day 11: Database Practice

**Training:** UPS Java Full Stack Training  
**Topic:** Database basics and SQL practice

## What I learned
- Difference between DBMS and RDBMS
- Difference between SQL and NoSQL databases
- Database, table, row, and column basics
- SQL command groups: DDL, DML, and DQL
- Creating tables and working with records
- Using constraints and changing table structures

## Practice files
- `sql/01_database_and_tables.sql` — create a database and tables
- `sql/02_insert_and_query.sql` — add records and retrieve data
- `sql/03_alter_table.sql` — practise changing table columns
- `sql/04_update_records.sql` — update records safely

## Run the examples
1. Open MySQL Workbench or your SQL command-line client.
2. Run the scripts in order.
3. Review the results after each `SELECT` statement.

## Important
These are practice examples. The employee data is fictional. Check the target rows before running `UPDATE` or `DELETE` statements. The examples use MySQL 8.4-compatible syntax.

## Skills practised
`CREATE DATABASE` · `CREATE TABLE` · `INSERT` · `SELECT` · `WHERE` · `ORDER BY` · `ALTER TABLE` · `UPDATE`
