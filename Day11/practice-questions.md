# Practice Tasks

Try these yourself after running `sql/campus_store.sql`.

1. Add a category named `Snacks`.
2. Add an item called `Water Bottle` with a suitable price and stock count.
3. Display items that cost more than 100.
4. List all items from the `Stationery` category.
5. Sort items by stock count from lowest to highest.
6. Increase the stock of item `103` by 3.
7. Add a `brand` column to the `items` table.
8. Explain why `category_id` is a foreign key in `items`.
9. Identify which statements in the script are DDL, DML, and DQL.
10. Explain the difference between `PRIMARY KEY`, `UNIQUE`, and `NOT NULL`.

## Challenge
Write a query that displays each category and the number of items listed under it.
