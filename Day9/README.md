# 🚀 Day 9 – Java Assessment

## Topics Covered
- Duplicate Elements in Arrays
- Custom Exception Handling
- Non-Repeating Elements
- Rectangle Area and Perimeter
- Array Rotation
- Inheritance and Method Overriding
- Classes and Objects

## Programs
1. `Dupli.java` — print duplicate elements
2. `InsufficientBalanceException.java` — custom exception example
3. `nonRepeating.java` — print non-repeating elements
4. `Rectangle.java` — area and perimeter
5. `Rotate.java` — left-rotate an array by one position
6. `Shape.java` and `Shapes.java` — inheritance and overriding
7. `Student.java` and `StudentCode.java` — student class and object

## Run a Program
From the `Assessment` directory, compile the required Java file(s):
```bash
javac Dupli.java
java Dupli
```

For the inheritance example, compile both source files:
```bash
javac Shape.java Shapes.java
java Shapes
```

For the student example:
```bash
javac Student.java StudentCode.java
java StudentCode
```

For the custom exception example:
```bash
javac InsufficientBalanceException.java
java BankDemo
```

> These are sample implementations based on the filenames, not recovered copies of the original assessment solutions.
